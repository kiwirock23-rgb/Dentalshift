# Dentalshift

Dentalshift เป็นโปรเจกต์ในระยะเริ่มต้น โดยมีแนวคิดสำหรับพัฒนาระบบจัดการตารางงานและเวรของทันตแพทย์ เพื่อช่วยให้คลินิกและทันตแพทย์วางแผนการทำงานร่วมกันได้สะดวกขึ้น

> แนวคิดข้างต้นเป็นทิศทางเบื้องต้น ยังไม่ได้กำหนดรายละเอียดหรือพัฒนาฟีเจอร์ใน repository นี้

## แนวคิดฟีเจอร์

- จัดการข้อมูลคลินิกและทันตแพทย์
- ประกาศกะงานและช่วงเวลาที่ต้องการทันตแพทย์
- ดูตารางงานและสถานะการรับกะ
- ตรวจสอบเวลาทำงานที่ซ้ำซ้อน

รายการนี้เป็นแนวทางสำหรับการพัฒนาในอนาคต ไม่ใช่ฟีเจอร์ที่ใช้งานได้แล้ว

## สถานะปัจจุบัน

Repository นี้ใช้เริ่มต้นโปรเจกต์และทดลองขั้นตอนการทำงานกับ Git และ GitHub ปัจจุบันยังไม่มีตัวแอปพลิเคชัน คำสั่งติดตั้ง หรือชุดทดสอบ

## ไฟล์ในโปรเจกต์

| ไฟล์ | รายละเอียด |
| --- | --- |
| `README.md` | ภาพรวม แนวคิด และสถานะของโปรเจกต์ |
| `git-demo.txt` | นิยายสั้นเรื่องน้ำท่วม ใช้ทดลองสร้างไฟล์ commit และ push ขึ้น GitHub |

## เริ่มต้นใช้งาน repository

ดาวน์โหลดโปรเจกต์ด้วย Git:

```bash
git clone https://github.com/kiwirock23-rgb/Dentalshift.git
cd Dentalshift
```

จากนั้นเปิดโฟลเดอร์ด้วยโปรแกรมแก้ไขข้อความที่ต้องการ เพื่ออ่านหรือแก้ไขไฟล์

## ขั้นตอนถัดไป

1. ยืนยันเป้าหมายและกลุ่มผู้ใช้งานของ Dentalshift
2. กำหนดฟีเจอร์สำหรับเวอร์ชันแรก
3. เลือกเทคโนโลยีและวางโครงสร้างแอปพลิเคชัน
4. เพิ่มวิธีติดตั้ง ใช้งาน และทดสอบเมื่อมีตัวแอปพลิเคชัน
